This repository contains thesis research built on top of
[EfficientViT](https://github.com/mit-han-lab/efficientvit) by the
[MIT HAN Lab](https://github.com/mit-han-lab).

The original source code was imported from commit
[`COMMIT_HASH`](https://github.com/mit-han-lab/efficientvit/commit/de7d7733cc0329f391b33f1f459271562ec27bd5).

development. It is not an official fork or distribution maintained by the
original authors.
